# Twitch 追台工具

Windows 多台直播追蹤工具，支援自由排版、觀看時間統計、開台通知及系統匣背景播放。

## 下載

[下載最新版](https://github.com/hobby248/twitch-tracking-tool/releases/latest)

目前版本：v1.3.1。請下載 `Twitch-Tracking-Tool-v1.3.1-Windows-x64.zip`，完整解壓後執行 `Twitch 追台工具.exe`，保留同目錄的其他檔案與資料夾。

需使用 Windows 10／11（64 位元），並安裝 Microsoft Edge WebView2 Runtime。

## 使用

1. 開啟程式，從右下角系統匣圖示開啟「設定」。
2. 點選「登入」，完成 Twitch 登入與授權。
3. 加入台主並調整追蹤順序，即可在程式內觀看。

按關閉可選擇縮至系統匣或結束程式，並記住選擇。

## 更新

已有程式內更新功能的版本，可在設定按「檢查更新」，或開啟「自動更新」（預設關閉）。更新會重新啟動並短暫中斷播放，保留登入、追蹤清單、觀看紀錄及現有擴充功能；新版啟動時會補上或更新內建 7TV，替換前保留備份；其他擴充功能不更動，較新 7TV 不降版。

初次安裝或沒有更新功能的舊版，請下載完整包。手動更新前先從系統匣結束舊版，不要刪除原有資料或自訂快取目錄。

發布包不包含個人 Access Token、Cookie、追蹤清單或測試快取。內建的 Twitch Client ID 為共用公開識別碼，並非個人 Token。
