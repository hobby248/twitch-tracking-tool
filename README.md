# Twitch 追台工具

Windows 本機 Twitch 多台追蹤工具。

目前版本：v1.1.1。功能檢查範圍見 [VERIFICATION.md](VERIFICATION.md)。

可以一次追蹤多個台主，直播中自動顯示，未開台自動隱藏，並在程式內用 Twitch 原站頁觀看直播。

## 下載

請到右側或上方的 **Releases** 下載最新版 zip。

下載後解壓縮，執行：

```text
Twitch 追台工具.exe
```

## 主要功能

- 一次追蹤多個 Twitch 台主
- 未開台自動隱藏，開台後顯示
- 啟動先查詢開台狀態，再依排序逐台載入；需要有效 Token，查詢失敗時等待重試
- 追蹤清單排序可當作觀看優先順序
- 省資源模式可限制同時載入台數（預設 4 台），依清單排序優先觀看；待命台不播放，仍可接收開台通知
- 多台直播自動排版
- 右鍵點選系統匣圖示開啟獨立設定視窗，可選擇排版欄數並自動儲存
- 每台可獨立放大
- 每台顯示本次與累計觀看時間，依帳號設定檔與已識別帳號分開保存，總時間不合併其他台主
- 計時器顯示在台主／帳號資訊區，觀看時間統計預設開啟，可在設定關閉並保留歷史
- 最小化或關閉視窗可縮至右下角系統匣並保留播放；雙擊圖示還原，右鍵選「結束」退出
- 每台可獨立調整音量
- 可建立多個帳號設定檔，並指定不同台主使用不同 Twitch 登入狀態
- 每個帳號設定檔可檢查 Twitch 登入狀態
- 可選擇要通知的台主，支援開台通知全開/全關與單獨開關
- 可匯入/匯出設定，不包含 Token 或 Client ID
- 可固定台主頁，避免直播格跳到其他頁面
- 可清除 WebView2 快取，不影響登入與追蹤清單
- 可設定閒置幾天後自動清理快取
- 可轉移 WebView2 資料/快取位置

## 第一次使用

1. 開啟 `Twitch 追台工具.exe`。
2. 右鍵點選右下角系統匣的程式圖示，選「設定」。
3. 點「登入」，完成 Twitch 登入與授權。
4. 輸入要追蹤的台主帳號。
5. 點「加入追蹤」。

忠誠點累積以 Twitch 原站登入狀態為準，請確認程式內 Twitch 頁面已登入並保持播放。

觀看時間每 5 秒取樣，只累計可確認正在前進的直播影片；本次時間以程式啟動為單位，取樣邊界可能少計數秒。統計每約 15 秒及正常退出時寫入本機 `watch-statistics.json`，清快取不會移除此檔。設定匯出包含統計開關，不包含統計歷史。

## 資料與隱私

本工具不會上傳你的資料。

以下資料只存在你的電腦：

- Twitch Access Token
- 追蹤清單
- WebView2 登入資料

匯出的設定檔只包含追蹤清單、帳號設定檔名稱、通知與介面設定，不包含 Twitch Access Token、Client ID 或登入 Cookie。

程式已內建共用的 Twitch Client ID，使用者不需要自行填寫；個人 Access Token 仍只儲存在本機。

預設本機資料位置：

```text
%LOCALAPPDATA%\TwitchPin
```

## 常見問題

### 打不開程式

請確認電腦已安裝 Microsoft Edge WebView2 Runtime。多數 Windows 10 / 11 電腦已內建。

### 忠誠點沒有累積

請確認：

- 程式內 Twitch 原站頁已登入
- 直播頁面有正常播放
- Twitch 帳號本身符合該台忠誠點累積條件

### 清除快取會登出嗎？

不會。設定裡的「清除快取」只清暫存快取，不會清除 Twitch 登入、Token 或追蹤清單。

### 更改快取位置會怎樣？

更改的是 WebView2 資料/快取位置。按「轉移位置」後，程式會在下次啟動 WebView2 前把既有 WebView2 資料轉移到新位置，盡量保留 Twitch 登入狀態與各帳號 Profile。
